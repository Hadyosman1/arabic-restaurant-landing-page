# Arabic Restaurant Landing Page

This is a modern and responsive landing page for a restaurant, built with [Next.js](https://nextjs.org) and styled using [Tailwind CSS](https://tailwindcss.com).

## Features

- **Responsive Design**: Looks great on all devices, from mobile to desktop.
- **Fast Performance**: Optimized for speed and performance.
- **SEO Friendly**: Built-in SEO features to help your site rank better.
- **Easy to Customize**: Clean and modular codebase for easy customization.
- **Modern UI**: Sleek and modern user interface.

## Getting Started

To get started with the development server, run:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- **`src/app`**: Contains the main application components.
- **`public`**: Contains static assets like images and icons.
